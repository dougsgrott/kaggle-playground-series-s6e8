## Quick start

```bash
uv sync
uv run kaggle competitions download -c playground-series-s6e8 -p data/ && (cd data && unzip -o *.zip && rm *.zip)
uv run python scripts/make_folds.py     # -> data/folds.npy, the frozen partition
uv run python scripts/check_env.py      # gate: libraries, GPU, shapes, invariants
uv run python scripts/benchmark.py      # real per-member training cost
```

## Knowledge base

`wiki/` and `analysis/` are generated by [`kaggle-wiki-kit`](../kaggle-wiki-kit) and gitignored —
a mirror of the competition pages, 49 discussion threads, 582 cleaned competitor notebooks, and
leaderboard snapshots. Refresh with `uv run wikikit daily`. Never hand-edit them.

The single richest asset is `analysis/nb_clean/<author>__<slug>.py`; `analysis/nb_priority.md`
ranks the 182 high-signal notebooks. Competition rules 2.6 and 3.6.b make all of it reusable —
cite the source path when lifting something.
